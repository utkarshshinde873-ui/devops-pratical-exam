Git & GitHub

A simple guide for tracking, sharing, and collaborating on code

Git GitHub Commands Workflow

What is Git?

Git is a free, open-source version control system. It records changes to files so you can review history, undo mistakes, and work on different features without disrupting the main project.

A repository (or repo) is a project folder that Git tracks.

What is GitHub?

GitHub is a cloud platform for hosting Git repositories. It adds collaboration tools such as pull requests, issue tracking, code reviews, and project dashboards.

Git works on your computer; GitHub stores and shares repositories on the internet.

Common Git Commands

git init                    # Start a repository
git clone <url>             # Copy a remote repository
git status                  # View changed files
git add <file>              # Stage a file
git commit -m "message"     # Save a snapshot
git push                    # Upload commits
git pull                    # Download changes
git branch <name>           # Create a branch

Basic Workflow

1. Create

Make a change or add a new file.

2. Stage

Choose the changes to include with git add.

3. Commit

Save a clear description with git commit.

4. Share

Send commits to GitHub with git push.
